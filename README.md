# Клон приложения AviaSales

## Описание
Клон известного приложения авиасейлс с функциональностью для поиска рейсов и покупки билетов.

## Особенности
1. Стартовый экран: Поля для ввода данных и афиша событий из разных городов, получаемая с сервера.
2. Поиск рейсов: Пользователь может выбрать города и выполнить поиск.
3. Результаты поиска: Отображение рейсов от различных авиакомпаний, данные также получаются с сервера.
4. Настройка дат: Возможность установить дату вылета (не ранее сегодня) и дату обратного билета (не ранее даты вылета).
5. Получение списка билетов: После настройки есть возможность получить полный список билетов от сервера
